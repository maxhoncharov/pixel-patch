# Pixel Patch — сторінки застосунку

Підтримка, політика конфіденційності та умови використання для гри
**Pixel Patch**. Роздаються GitHub Pages.

Джерело — тека `site/` у репозиторії гри: тексти описують те, що гра справді
робить, тож мінятись вони мусять разом із нею. Правити тут напряму не варто —
правки загубляться при наступному копіюванні.
